# Glowup ✨

A cute, aesthetic Flutter app for managing your daily life — reminders, habits, flights, grocery lists, fitness tracking, and more.

## Features

- 🌸 **Reminders** — Set one-time or repeating reminders with emoji
- 💖 **Habits** — Track daily habits with streaks and progress
- ✈️ **Flights** — Monitor upcoming flights with live countdowns
- 🛒 **Grocery & Shopping Lists** — Check off items on the go
- 🏃 **Fitness** — Log walks and workouts
- 💧 **Water Reminder** — Stay hydrated
- 📚 **Learning Goals** — Track progress on things you're learning
- 💳 **Subscriptions** — Keep tabs on monthly spending
- 🏋️ **Workout Planner** — Plan and log workout sessions
- 🏠 **Home Screen Widget** — A big, beautiful Android widget showing all your data at a glance

## Tech Stack

- Flutter (Dart)
- Provider for state management
- SQLite via `sqflite`
- Local notifications via `flutter_local_notifications`
- Home screen widgets via `home_widget`
- Shared preferences for persistence

## Getting Started

```bash
flutter pub get
flutter run
```

Requires Flutter 3.x and Android SDK 21+.
